# OpenPLG
A UI based software that allows to user to easily generate large scale terrain for CGI, game design ect...

**Quick Start:**
1. Download the zip, double click into the file, DO NOT extract the launcher, double click to run. THIS MAY TAKE A WHILE, UP TO 5 MINUTES. (If you get a windows warning error click more info and run anyway, its not dangerous I promise)
2. The terrain should auto generate, then simply adjust the values to your desire
3. Click export package, select desired location and give it a while to export

**Features:**
- Pan either side of the landscape for connecting features and larger terrain
- Detail modifies the amount of noise inside the terrain
- Scale modifies the scale of the noise inside the terrain
- y stretch vertical stretches the mesh
- Water level changes the current level of the water plane
- Weathering modifies physical weathering of the landscape
- Thermal erosion modifies the erosion of heat to the landscape
- Hydro erosion modifies the way in which water modifies the landscape
- Exports terrain as a .ply, exports a heightmap slope mask snow mask and water mask

**Source:**
This project is based of the pyvista library which handles some of the more complicated calculations
